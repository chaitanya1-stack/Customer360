# Start here

1. **See the result:** open `outputs/figures/executive_summary.png`.
2. **Read the story:** open `outputs/REPORT.md` or the main `README.md`.
3. **Follow the code:** open `RetailLens_Walkthrough.ipynb`. Its 12 Python cells include actual recorded outputs. The SQL and reusable Python modules are included in full.
4. **Run it:** follow the Python 3.12 setup in `README.md`, then run `python run.py` from this folder. The original 1,067,371-row source dataset is included, so no account or API key is needed.
5. **Prepare for interviews:** study `docs/INTERVIEW_GUIDE.md` and `docs/DATA_DICTIONARY.md`. Use `outputs/RESUME_BULLETS.md` only after you can explain the work.

This delivered run selects three K-Means clusters on 5,256 historical customers. It does not claim one million customers or orders, classification accuracy, or a measured increase in retention/revenue. Read the methodology and limitations with the results.
